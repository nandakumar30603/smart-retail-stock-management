
# 🛒 Smart Retail Stock Management System

## 📌 Project Overview
Smart Retail Stock Management System is a data-driven solution designed to optimize inventory control in retail environments using Machine Learning and data analytics.

This project was developed as part of the **AI Club Project at CMR Engineering College (UGC Autonomous)**.

## 🎯 Objectives
- Automate inventory tracking
- Improve demand forecasting
- Prevent stockouts and overstocking
- Reduce operational costs
- Enhance customer experience

## 🧠 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- HTML, CSS

## 🏗️ Project Structure
```
smart-retail-stock-management/
│── README.md
│── requirements.txt
│── app.py
│── data/
│── screenshots/
```

## 🚀 How to Run
1. Install dependencies:
```
pip install -r requirements.txt
```
2. Run the application:
```
streamlit run app.py
```
